# The CLI versions the adapters were verified against.
#
# `plan-review doctor` compares each tool's current version against the
# value here and WARNS on any difference. Exact match, not a floor: compatibility
# was measured at exactly these versions, and nothing tells us a newer release
# preserves the behaviour the adapters depend on. A warning is not a refusal to
# run -- a newer CLI usually works.
#
# What drift actually threatens, per adapter:
#   codex   the banner. adapters/codex.sh parses `sandbox:`, `model:`,
#           `reasoning effort:` and `session id:` out of stderr, and refuses to
#           trust a review when the sandbox line is missing or unexpected. A
#           banner change is a failed round, not a wrong one.
#   agent   the mid-run model-switch notice, which Cursor emits only as prose
#           ("Switched to ..."). Reworded, the adapter would record a model that
#           did not answer.
#   agy     the --output-format stream-json lines the adapter asserts on: an `init`
#           line carrying permission_mode, one step_update per step transition with
#           tool_name and tool_info, and a `result` line with status, response and
#           conversation_id (the old envelope, unchanged, on one line of the stream).
#           adapters/agy.sh refuses to record a review when the init line is missing
#           or names a mode it did not ask for, and when no run_command step reached
#           DONE -- so a stream change is a failed round, not a wrong one, which is
#           what claude's entry below already says about its own init line.
#   claude  the --output-format stream-json `init` line: model, permissionMode,
#           claude_code_version. adapters/claude.sh refuses to record a review
#           when that line is missing or reports a permission mode it did not
#           ask for, so a stream change is a failed round, not a wrong one.
#           Also at risk: --safe-mode, which is what stops the TARGET repo's
#           .claude/settings.json hooks executing inside the jail.
#
# Format: <tool> <version>. One per line, # starts a comment.
# Update it after re-running the probes recorded in the process notes.
