# The CLI versions the adapters were verified against.
#
# `plan-review doctor` compares each tool's current version against the
# value here and WARNS on any difference. Exact match, not a floor: compatibility
# was measured at exactly these versions, and nothing tells us a newer release
# preserves the behaviour the adapters depend on. A warning is not a refusal to
# run -- a newer CLI usually works.
#
# What drift actually threatens, per adapter:
#   codex   the banner. adapters/codex.sh parses `sandbox:`, `model:`,
#           `reasoning effort:` and `session id:` out of stderr, and refuses to
#           trust a review when the sandbox line is missing or unexpected. A
#           banner change is a failed round, not a wrong one.
#   agent   the mid-run model-switch notice, which Cursor emits only as prose
#           ("Switched to ..."). Reworded, the adapter would record a model that
#           did not answer.
#   agy     the --output-format json envelope: status, response, conversation_id.
#   claude  the --output-format stream-json `init` line: model, permissionMode,
#           claude_code_version. adapters/claude.sh refuses to record a review
#           when that line is missing or reports a permission mode it did not
#           ask for, so a stream change is a failed round, not a wrong one.
#           Also at risk: --safe-mode, which is what stops the TARGET repo's
#           .claude/settings.json hooks executing inside the jail.
#
# Format: <tool> <version>. One per line, # starts a comment.
# Update it after re-running the probes recorded in the process notes.

# Verified 2026-08-28 by the acceptance matrix, and by the containment probe of
# the same week (docs/process/probes/2026-08-28-cursor-containment/). Re-measured
# at THIS version: `agent about --format json` answers with cliVersion (and
# userEmail, which the doctor never echoes), and `agent status --format json`
# answers with isAuthenticated -- lib/doctor.sh uses both, so identity and auth
# are structured, and the 60-second --list-models call is left to pin validation
# alone. A smoke-scale round recorded all four meta lines.
#
# The mid-run model-switch notice is the one promise this line does NOT vouch
# for, and the narrowing is deliberate rather than an oversight. Cursor emits it
# only as prose ("Switched to ..."); the format was verified at pin time and
# CANNOT be provoked on demand (probe P5), so no run since has re-read it. Drift
# in that prose is detected only by a live swap actually happening -- until then
# adapters/agent.sh could be recording a model that did not answer, and nothing
# here would know. Treat the notice as pinned-by-history, not pinned-by-test.
#
# Containment, by contrast, WAS re-measured at this version: Cursor's own
# sandbox is the write barrier, and the earlier "unconfined" reading was the
# probing host's own ~/.cursor `approvalMode: "unrestricted"` making
# `--sandbox enabled` inert. adapters/agent.sh now runs from a private
# CURSOR_CONFIG_DIR that pins the safe mode, so the operator's setting cannot
# reach the reviewer.
agent 2026.08.25-3e8eec8

# response" -- was measured once, in probe P1 at agy 1.1.15, and has not been
# re-provoked live since. The matrix proves only that the installed CLI accepts
